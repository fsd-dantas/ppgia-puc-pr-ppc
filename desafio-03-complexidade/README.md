# Desafio 3 — Análise de Complexidade

Análise do espaço de estados e complexidade dos algoritmos de busca
aplicados ao problema dos missionários e canibais.

## Tópicos

1. Modelagem dos estados do sistema
2. Contagem de estados totais e válidos
3. Fator de ramificação
4. Crescimento do espaço de busca (polinomial vs. exponencial)
5. Complexidade de DFS e BFS neste domínio
